# InterviewAce-AI-Mock-Interview-System
InterviewAce is an AI-powered mock interview platform built using React.js, Spring Boot, MySQL, JWT, and Google Gemini API. It enables users to practice technical interviews, receive AI-generated feedback, manage interview sessions securely, and improve their interview skills through an interactive and user-friendly interface.
## 🚀 Features

- User Registration & Login
- JWT Authentication
- Topic-wise Mock Interviews
- AI Feedback using Google Gemini API
- Submit Answers & Get Evaluation
- Interview Result Dashboard
- MySQL Database Integration
- RESTful APIs
